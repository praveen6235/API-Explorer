# API Explorer 🚀

API Explorer is a modern web application built with **React and Vite** that allows users to explore and interact with public APIs.  
The application fetches real-time data from APIs and presents it in a clean and responsive user interface.

# 📌 Project Overview

API Explorer helps developers and learners discover APIs and understand how data can be fetched and displayed in modern web applications.  
The project demonstrates practical usage of **React components, API integration, routing, and deployment**.

This project was built as part of my learning journey in **modern frontend development**.

---

# ✨ Features

- Explore and search APIs
- Fetch real-time API data
- Responsive design for mobile and desktop
- Client-side routing using React Router
- Modern UI using Bootstrap
- Fast build system using Vite
- Live deployment using Vercel
